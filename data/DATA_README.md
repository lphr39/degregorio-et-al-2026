# Data Files

The datasets required for replication are not included in this repository due to licensing restrictions.

## Data Available Upon Request

The following data files should be placed in this folder to run the replication:

| File | Description |
|------|-------------|
| `dataset_jie.dta` | Main firm-level panel dataset (1,655 firms, 15 EMEs, 2001–2016) |
| `Issuance Firm-Year.dta` | Bond issuance data by firm and year |
| `exrates.dta` | Exchange rate data by country and year |
